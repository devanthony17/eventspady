# Hero videos

The hero plays three looping background videos, crossfading between them.
Drop your footage here with these exact names:

    hero-1.mp4   hero-1.webm   (optional)
    hero-2.mp4   hero-2.webm
    hero-3.mp4   hero-3.webm

Until a file exists, the hero falls back to the animated backdrop at
`public/images/hero/motion-N.svg`, so the section always looks alive.

Guidance: 8-15s loops, 1920x1080, no audio track, H.264 (mp4) and/or VP9 (webm),
under ~4 MB each. They are muted, autoplaying and `playsInline`.
